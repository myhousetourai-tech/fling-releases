First‑time notes

Mac: unzip, drag Fling to Applications, open it. macOS will say it can’t check the developer the first time: go to System Settings → Privacy & Security and click Open Anyway. Once.

Android: open the downloaded APK. Allow “install from this source” once, then Install. Fling asks for its few permissions on first launch.

Windows: run the installer; on the “Windows protected your PC” screen click More info → Run anyway. Once.

Pairing: open Fling on both devices on the same Wi‑Fi. One shows a 6‑digit code, you type it on the other. After that they find each other on their own.

Updates: each app tells you when a newer version is here and installs it with one tap.
